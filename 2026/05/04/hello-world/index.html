Vol.01 Atomsk创建Si/SiC基础结构

发表于2026-05-04|更新于2026-05-25|博客记录
|浏览量:

摘要📌

  • 当前最终采用的模型为 12×12 Si / 15×15 3C-SiC(001) 界面 slab：Si 位于下方作为基底，3C-SiC 位于上方，SiC 的 C 端面接触 Si；z 方向加约 20 Å 真空层。
  • 面内匹配采用保持 Si 基底尺寸不变、对 3C-SiC 施加约 -0.34% 的 x/y 面内压缩。12×a(Si)=65.172 Å，15×a(SiC)=65.394 Å，失配约 0.34%。
  • 经过错误排查后确认：先前界面最近 Si-C 距离为 3.2478 Å 的构型不合理，属于界面接触过远/未有效成键的结构。当前修正方案通过给 Si 基底上方加 0.53 Å 的 z 向间距调节，并采用 C Si 顺序创建 SiC，以保证 C 端面接触 Si。
  • 当前 LAMMPS 使用 SiC.tersoff 势函数、boundary p p f、固定底部 10 Å Si 基底、不使用 box/relax，先 CG 粗弛豫，再 FIRE 精弛豫。最终 FIRE 后 Fmax=2.047×10^-5 eV/Å，说明 0 K 经典势几何弛豫已经非常充分。
  • 对 FIRE 输出 data 文件进行定量检查后，原子数、元素比例、z 向层次、真空层、C 端面、最近邻距离均合理；界面处存在周期性的浅蓝色局部凸起，应主要理解为 12:15 近重合界面中局部 Si-C 成键与配位差异，不宜直接视为错误。
  • 当前结构可称为“ LAMMPS/SiC.tersoff 经典势下充分弛豫后的 Si/3C-SiC(001) C 端面界面结构 ”。若后续需要电子结构、界面能、差分电荷密度、DOS 等高精度结论，建议继续做 DFT；若只讨论经典势下的界面几何，可作为最终 LAMMPS 结构使用。

模型目标与物理设定📝

本阶段的目标是构建一个中等尺寸的 Si / 3C-SiC(001) 界面模型，并使用 LAMMPS 对其进行经典势预弛豫。模型用于描述 Si 基底上方外延/接触 3C-SiC 薄层的原子结构。

项目 当前设置
界面体系 Si / 3C-SiC
晶面取向 Si(001) / 3C-SiC(001)
平面内匹配 12×12 Si / 15×15 SiC
z向厚度 Si: 8个常规晶胞；SiC: 8个常规晶胞
基底与上层 Si为下方基底，3C-SiC为上层
端面设定 C端面接触 Si基底
真空层 z方向加约 20 Å 真空层
LAMMPS边界 boundary p p f，即 x/y-周期，z-非周期固定边界
基底约束 固定底部 10 Å 的 Si 原子

注意事项💡

Lammps弛豫

结构弛豫：该模型仅为几何拼接，建议在 LAMMPS 中进行能量最小化与 MD 弛豫

  • 粗弛豫，采用 cg 算法进行能量最小化
  • 细弛豫，采用 fire 算法进行能量最小化

终止面选择

  • C Si→ C‑terminated interface
  • Si C→ Si‑terminated interface

shift 与 wrap 指令使用注意

  1. -shift 最容易错在：只移动原子，不移动盒子

4:5 方案与 12:15 方案区别✨

我曾经构建过 4×4 Si / 5×5 SiC 的 4:5 匹配方案，且其中 SiC 是基底。当前工作则是 12×12 Si / 15×15 SiC 的三倍扩展模型，但基底方向和应变承担方发生了变化。

对比项 曾经的 4:5 方案 当前 12:15 方案
平面内比例 4×4 Si / 5×5 SiC 12×12 Si / 15×15 SiC
尺寸 较小模型 中等尺寸模型，是 4:5 的三倍扩展
基底 SiC 为基底 Si 为基底
应变处理 对 Si 做 +0.34% 拉伸以匹配 SiC 对 SiC 做 -0.34% 压缩以匹配 Si
上层材料 Si 在上方 3C-SiC 在上方
LAMMPS 流程 最小化后还做 NVT 平衡 CG 粗弛豫 + FIRE 精弛豫；当前不做 NVT
基底固定 旧脚本未明确固定底部基底 固定底部 10 Å Si 基底
最终结构定位 经典势热平衡/初步弛豫结构 经典势 0 K 充分弛豫结构

从 LAMMPS 操作角度看，以前比现在多了 NVT 平衡。但旧结构“界面看起来更融合”不能简单说明其更合理，因为 NVT 后的单帧包含热振动，且旧模型没有固定基底；当前静态界面模型的合理性主要应依据最近邻距离、界面成键、异常短键、总能量与最终力收敛共同判断。

对于 12×12 Si / 15×15 SiC, 当前 FIRE 结果已经达到非常充分的经典势力收敛；如果目标是 0 K 几何弛豫，不需要再继续做 CG 或 FIRE。若未来要研究 300 K 热稳定性，可在当前结构基础上做 NVT，再进行一次最终 minimize；但不建议直接把 NVT 最后一帧当作静态最终结构。
