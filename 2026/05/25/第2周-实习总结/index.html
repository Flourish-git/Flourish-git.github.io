PWM互补输出

简介

同一个 PWM 信号，输出两路波形，一路为正向 PWM，另一路为反向 PWM。当 A 路为高电平时，B 路为低电平；当 A 路为低电平时，B 路为高电平。

CHx = 正相 PWM, CHxN = 互补 PWM(注意：图中强调的是逻辑相反，不是指输出反向电压)。CH1 = 3.3V / 0V，CH1N = 0V / 3.3V

主要用途

PWM 互补输出最常用于：半桥、全桥、H 桥、电机驱动、逆变器、开关电源。
比如一个半桥电路：

上管和下管不能同时导通。上管导通时，下管关闭;下管导通时，上管关闭.这时候就很适合用 PWM 互补输出：CH1 控制上管，CH1N 控制下管。
这里补充一句：为什么不能让上下管同时导通？
因为如果上管和下管同时导通，就等于：VCC → 上管 → 下管 → GND
这相当于电源直接短路，叫做 桥臂直通 或 shoot-through。后果可能是：MOS 管发热、电机驱动芯片烧毁、电源被拉垮、单片机复位。
所以互补输出通常还要配合一个东西：死区时间。

死区时间

死区时间就是：上管关断之后，先等一小段时间，再打开下管；下管关断之后，也先等一小段时间，再打开上管。

普通 PWM 和互补 PWM 的区别

类型 输出数量 波形关系 常见用途
普通 PWM 1 路 只有一路 PWM LED 调光、舵机、电机简单调速
互补 PWM 2 路 一路高时另一路低 半桥、全桥、H 桥、电机驱动、逆变器
带死区互补 PWM 2 路 互补且中间留空档 MOS/IGBT 桥式驱动，最常用

自适应波特率

简介

波特率自适应，也叫自动波特率检测。简单说，接收设备在不知道对方串口波特率的情况下，通过分析对方发来的数据波形，自动判断通信速率，并把自己的串口波特率调整到一致。

实现方法

利用已知特征字节（最经典）

通信双方约定：连接后，发送方先发一个固定的同步字符（比如 0x55= 01010101，位跳变最密集，最容易测量。也有些会用：0x7F、回车符 Enter、’A’、’U’具体看芯片或协议要求）。接收方的定时器去测量相邻下降沿之间的时间间隔，反推出一位的宽度，从而算出波特率。

硬件自动波特率检测（部分 MCU 内置）

STM32 的 USART 有 Auto Baud Rate 模式（ABRM），如部分 STM32F0、F3、F4、F7、H7 等系列。硬件自动捕获起始位到第一个比特的计时，完成后把算出的波特率写入 BRR 寄存器，全程不需要 CPU 干预。
但是 STM32F1 系列通常没有很方便的硬件 Auto Baud 功能，如果要做，一般需要自己用定时器输入捕获或外部中断测 RX 波形，然后计算波特率。

倍频模式

“一倍频/二倍频/四倍频”说的是正交编码器 A、B 两相信号的计数方式，编码器一般输出两路方波：A 相 和 B 相，相位差 90 度。电机转一格时，A/B 会经历类似：

一倍频：只数一个边沿
比如只在 A 相上升沿 计一次。一个完整周期只加 1。
二倍频：数 A 相两个边沿
比如 A 相上升沿 + A 相下降沿 都计数。一个完整周期加 2。
四倍频：A、B 两相的所有边沿都计数
A 上升、A 下降、B 上升、B 下降 都计数。一个完整周期加 4。

嵌入式 C 语言常见关键词

总体分类

嵌入式 C 语言中的关键词大致可以分为三类：

类型 代表关键词 作用
标准 C 关键词 const、volatile、static、extern、register、auto 控制变量属性、生命周期、作用域、编译器优化行为
嵌入式/编译器扩展关键词 xdata、code、data、idata、pdata、bit、sbit、sfr 指定存储区域、特殊寄存器、位变量等，常见于 8051/Keil C51
中断/函数属性相关关键词 interrupt、using、reentrant、__weak、__packed、__IO 描述中断函数、寄存器组、可重入函数、结构体对齐、寄存器访问等

const

const 表示变量的值不应该被程序修改。

这表示 max_speed 在程序中不能被普通代码修改。常用于 PID 参数、校准参数、固定阈值等。
volatile const 表示：

  • 对程序来说，这个变量不应该被软件修改，即 const
  • 但它的值可能被硬件改变，即 volatile
